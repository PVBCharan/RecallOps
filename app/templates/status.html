💡 Setup Guide

Ollama provides local LLM inference for evidence synthesis and recommendation generation.

  1. Install Ollama from ollama.ai
  2. Run ollama pull llama3.2 for the text model
  3. Run ollama pull llava for image analysis
  4. Start with ollama serve

Hindsight is the experience memory service. The app falls back to local SQLite search when Hindsight is unavailable.

Note: Core case management and evidence storage work without Ollama or Hindsight — only AI-powered analysis requires them.
